# Bayti-Real-Estate-Platform
AI-powered full-stack real estate platform tailored to the Lebanese property market, developed using Flask, SQLAlchemy, and NLP techniques.

Project Overview

Bayti is a full-stack real estate web application designed to address the specific needs of the Lebanese property market through intelligent property discovery and personalized recommendations.

Business Objective

To simplify property searches and connect potential buyers and tenants with relevant properties based on their preferences and budgets.

Key Features
- User authentication
- Property listings
- Advanced search and filtering
- Personalized property recommendations
- Favorites management
- Relational database management
Technologies Used

Python, Flask, SQLAlchemy, HTML, CSS, JavaScript and Natural Language Processing.

AI-Assisted Development

Generative AI tools supported development, debugging, problem-solving and optimization, with manual review and validation.
